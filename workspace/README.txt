This is the firm's working directory.

Drop documents here (.txt, .md, .csv, .html). The assistant in the sidebar can
read, edit, summarize, and organize them. Run `pnpm ingest` after adding new
files if you have Supabase running — it will embed everything so the assistant
can do semantic search.

Subfolders are encouraged — e.g.:
  matters/<client-name>/
  templates/
  precedents/
